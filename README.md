## 📖 Descripción del Proyecto
**AulaSound** es una aplicación web desarrollada para asistir en prácticas de laboratorio de física acústica. Permite capturar audio en tiempo real mediante el micrófono del dispositivo, procesar señales y realizar mediciones empíricas estructuradas en tres módulos experimentales clave para la ingeniería.

---

## 🧪 Módulos Experimentales

1. **Módulo 1: Frecuencia y Ondas (Osciloscopio)**
   * Visualización de ondas sonoras en tiempo real mediante la Web Audio API y AnalyserNode.
   * Análisis perceptual y diferenciación entre frecuencias graves y agudas.
   * Sistema de captura de evidencias y almacenamiento de mediciones.

2. **Módulo 2: Acústica en Sala de Clases**
   * Comparador interactivo de posiciones (Muralla vs. Centro).
   * Análisis de reflexiones y comportamiento del campo sonoro en espacios confinados.

3. **Módulo 3: Propagación del Sonido**
   * Estudio empírico y teórico de la ley del inverso del cuadrado.
   * Evaluación de la atenuación de la señal acústica en función de la distancia.

---

## 🛠️ Tecnologías y Stack
* **Frontend:** HTML5, Tailwind CSS (Diseño responsive y componentes de interfaz con estética Glassmorphism).
* **Lógica y Procesamiento:** JavaScript Vanilla (Manipulación del DOM, gestión de estados y Web Audio API).
* **Despliegue:** GitHub Pages.

---

## 🚀 Instrucciones de Uso
1. Ingresa a la plataforma a través del enlace de [GitHub Pages](https://jaaviiieraa.github.io/aulasound/).
2. Sigue los pasos de la **Guía Interactiva (Tutorial)** al iniciar la aplicación.
3. Concede los permisos de micrófono solicitados por el navegador para habilitar el osciloscopio y las mediciones en vivo en cada módulo.
